📘 GARP RAI Quiz Tool

Pick how many questions to draw from each chapter, then take a randomized quiz with shuffled answer order.

Add a new question set

Upload a JSON file describing your questions and they'll show up in Build Quiz alongside the built-in modules. Imported sets are saved in this browser (localStorage), so they'll still be here next time you open this file — but they won't transfer to a different browser or device unless you re-import the file there.

Expected JSON format:

{
  "Module Name": {
    "1": {
      "title": "Chapter title",
      "questions": [
        {
          "q": "Question text?",
          "options": { "A": "Option A text", "B": "Option B text", "C": "Option C text", "D": "Option D text" },
          "answer_letter": "B"
        }
      ]
    }
  }
}

Or import from Excel

Upload an .xlsx/.xls file with one question per row: Column A = question text, Columns B–E = answer options A, B, C, and D (in that order), and Column F = the letter (A/B/C/D) of the correct option. The first row is treated as a header and skipped. Each sheet in the workbook becomes one chapter (the sheet name is used as the chapter title); give the whole file a set name below — this groups all its sheets/chapters together in Build Quiz.
