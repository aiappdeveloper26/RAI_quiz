Add a new question set

Upload a JSON file describing your questions and they'll show up in Build Quiz alongside the built-in modules. Imported sets are saved in this browser (localStorage), so they'll still be here next time you open this file — but they won't transfer to a different browser or device unless you re-import the file there.

Expected JSON format:

{
  "Module Name": {
    "1": {
      "title": "Chapter title",
      "questions": [
        {
          "q": "Question text?",
          "options": { "A": "Option A text", "B": "Option B text", "C": "Option C text", "D": "Option D text" },
          "answer_letter": "B"
        }
      ]
    }
  }
}

Load a dataset from a URL (great for GitHub)

This tool can't reliably save imported data in this browser (see the warning above if it appears). A robust workaround: commit your question file (JSON or .xlsx) to a GitHub repo, then load it here by URL — the file on GitHub becomes your permanent storage instead of the browser. For a public repo, use the raw file URL, e.g. https://raw.githubusercontent.com/USER/REPO/main/questions.json. You can also auto-load on page open by visiting this-tool.html?dataUrl=<encoded raw URL>&dataType=json&dataName=Module%204 — bookmark that link and the dataset loads automatically every time.

Or import from Excel

Upload an .xlsx/.xls file with one question per row: Column A = chapter name, Column B = question text, Columns C–F = answer options A, B, C, and D (in that order), and Column G = the letter (A/B/C/D) of the correct option. The first row is treated as a header and skipped. Rows are grouped into chapters based on the value in Column A (rows with the same chapter name become one chapter, in the order they first appear); a blank chapter cell falls back to a "General" chapter. If the workbook has multiple sheets, all sheets are read and combined the same way. Give the whole file a set name below — this is the dataset name shown in Build Quiz.
